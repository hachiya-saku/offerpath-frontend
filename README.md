# OfferPath

[日本語](README.md) | [简体中文](README.zh-CN.md) | [English](README.en.md)

OfferPath は、複数の求人サービスや企業サイトに分散した求人情報を一元管理するための求職管理プラットフォームです。応募状況、求人とのスキルマッチ度、選考の進捗を一つのワークスペースで確認できます。

現在はフロントエンドの静的プロトタイプを実装しています。今後は NestJS と PostgreSQL を利用した API、認証、データ永続化を追加し、フルスタックの個人開発プロジェクトとして完成させる予定です。

## 解決したい課題

- 求人情報が複数のサービスに分散している
- 応募後の選考状況を継続して管理しにくい
- 求人要件と自分の技術スタックの差分が見えにくい
- 応募数や面接移行率などを振り返る仕組みがない

## 現在の実装

- ログイン画面
- 求人数、進行中の選考、平均マッチ度を表示するダッシュボード
- ECharts による求人ステータス分布
- 求人一覧、キーワード検索、ステータス・媒体フィルター
- 新規求人フォームとスキルタグ入力
- 求人詳細、スキルマッチ分析、選考タイムライン
- 個人プロフィールと技術スタック一覧
- デスクトップ用サイドバーとモバイル用ドロワーナビゲーション
- ダークテーマを基調としたレスポンシブ UI

現在のデータはすべて静的なサンプルです。ログイン、保存、編集、削除はまだバックエンドに接続されていません。

## 求人ステータス

```text
検討中 -> 応募済み -> 書類選考 -> 一次面接 -> 二次面接 -> 三次面接 -> 最終面接 -> Offer
   \________________________________________________________________________ 不採用
```

実際の選考フローは企業ごとに異なるため、最終的にはステータスを自由に変更できる設計を予定しています。

## 今後の開発

1. NestJS と PostgreSQL によるバックエンド基盤
2. ユーザー登録、ログイン、JWT 認証、ユーザー単位のデータ分離
3. 求人の作成・取得・更新・削除とページネーション
4. 選考ステータスの更新履歴
5. 個人スキル管理と重み付きマッチ度計算
6. ダッシュボードの集計 API と転換率
7. 求人票テキストの AI 構造化抽出
8. Docker Compose と本番環境へのデプロイ

## ローカル実行

Node.js `^20.19.0 || >=22.12.0` が必要です。

```bash
npm install
npm run dev
```

デフォルトでは <http://localhost:5173> で起動します。

```bash
npm run build    # 型チェックと本番ビルド
npm run lint     # 静的解析
npm run preview  # 本番ビルドのプレビュー
```
